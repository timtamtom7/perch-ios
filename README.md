# perch

Travel planning with emissions tracking and packing lists.

## What it does

- Trip planning
- CO2 breakdown
- packing lists
- flight tracking
- PDF export

## Targets

- iOS

## Structure

Key types:

- ``TravelInsightsService``
- ``DeepTravelAnalysisService``
- ``FlightTrackerService``
- ``PackingListStore``
- ``PDFExportService``
- ``TemplateStore``
- ``TravelDetectionManager``

The CO2 breakdown chart and automatic travel detection are the distinctive parts.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
